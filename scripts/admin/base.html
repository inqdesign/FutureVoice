유저 활동

이 사람들은 누구인가

애플 비공개 릴레이 주소 뒤의 실제 신원 — 웨이트리스트 가입 이메일(user_waitlist_mapping)과 온보딩에서 본인이 쓴 자기소개(public_personas)를 붙였어요. 자기소개는 클릭하면 전체가 펼쳐져요.

일별 활동

활동 = 그날 서버 원장에 기록이 있는 계정. 대화 턴은 통화 중 Gemini 응답 호출 수예요.

유저별 현황

마지막 활동 기준 최신순. 통화 시간은 8/10부터 측정된 값이라 그 이전의 대화는 턴 수로만 남아 있어요.

연속 사용 (streak)

가입일을 0일에 맞춰 나란히 세운 차트예요 — 가입 시점이 달라도 행동 패턴을 겹쳐 볼 수 있어요. 파란 막대 하나가 연속으로 대화한 구간이고, 빈칸은 쉰 날이에요. Core 클럽 자격은 30일 연속인데, 실사용자 최장 기록은 아래에서 확인할 수 있어요.

돌아오기까지 걸린 시간

쉬었다가 다시 대화한 간격. 이탈이 아니라 휴지기라면 여기에 쌓여요.

가입 후 주차별 잔존

그 주에 한 번이라도 대화한 사람 수. 해당 주를 다 채운 유저만 셈에 넣어요.

활동 히트맵

칸의 진하기 = 그날의 서버 기록 수. 하루라도 색이 있으면 그날 앱을 실제로 썼다는 뜻이에요.

통화 세션 길이

8/10 이후 측정된 세션 기준.

턴 오류

통화 중 응답 생성이 실패한 턴 (client_events).

기능 사용

무료 기능의 일일 사용 기록(free_usage_daily) 누적 호출 수 — 전 계정 합산이라 개발 계정 토글의 영향을 받지 않아요.

유입 경로

웨이트리스트 15명이 어디서 왔는지 (waitlist.referrer). 앱 가입까지 이어져 매핑된 사람은 4명이에요.

데이터 주석

  • 통화 시간은 TalkMeter가 배포된 2026-08-10부터만 측정돼요. 베타 유저들의 7월 대화는 턴 수에는 있지만 통화 시간에는 0으로 보여요.
  • Watch 장면도 장면 단위 과금이 시작된 8/10 이후 기록이에요.
  • 이 페이지에는 실명·실제 이메일·자기소개가 들어 있어요. 아티팩트는 기본이 비공개예요 — 공유 링크를 만들지 마세요.
  • streak는 "대화한 날"(그날 대화 턴이 1개 이상) 기준이에요. 서버 기록만 있고 대화가 없던 날은 102일 중 4일뿐이라 활동일과 거의 같아요.
  • Core 클럽 자격(30일 연속, 하루 240초 이상 통화)은 아직 판정할 수 없어요 — 통화 시간이 측정되는 실사용자가 1명뿐이라, 하루 240초를 넘긴 날은 개발 계정에만 있어요.
  • 레벨(proficiency)은 전원 b1이라 온보딩 기본값일 가능성이 높아요 — 실력 지표로 읽지 마세요.
  • 웨이트리스트 매핑은 matched_by=manual, 즉 손으로 이어붙인 값이에요. 8/16·8/18 가입자 2명은 매핑이 없어요(TestFlight 직접 설치로 보여요).
  • 개발 계정 2개(본인 계정, android-dev-test)는 기본으로 제외돼요 — 본인 계정이 전체 활동의 대부분이라 포함하면 실제 유저의 패턴이 묻혀요.
