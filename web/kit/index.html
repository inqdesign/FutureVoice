nawana UI kit

앱 화면을 웹 컴포넌트로 옮긴 키트예요. 웹사이트에도, 캐러셀·릴스 녹화에도 같은 요소를 써요. 스크립트 한 줄로 불러오고, 태그로 놓으면 돼요.

<script type="module" src="/kit/nawana-ui.js"></script>

화면 글자(버튼, 안내)는 가장 가까운 lang을 따라요. ko면 한국어, 그 밖은 영어예요. 대화 문장은 학습 언어라 영어 그대로예요. 폰트는 이 폴더 위의 GeistPixel.ttf, Galmuri14.woff2를 읽어요.

nw-futureself

미래의 나 모자이크예요. 앱 셰이더(Futureself.metal) 수식을 그대로 옮겨서, 셀마다 해시로 숨 쉬고, 말할 때는 가운데에서 바깥으로 켜지고, 안쪽 그림자까지 같아요. 크기는 CSS로 정하고, 셀은 높이의 1/5이에요.

<nw-futureself mode="speaking" level="voice"></nw-futureself>
<nw-futureself mode="listening" level="0.5"></nw-futureself>
<nw-futureself mode="thinking"></nw-futureself>
<!-- 홈 링: 원형 + 링 그림자, 셀 12.8 고정 -->
<nw-futureself shape="circle" ring mode="idle" cell="12.8"
  style="width:220px;height:220px"></nw-futureself>

el.mode = "speaking"; el.level = 0.7;   // 실시간 변경

nw-call

통화 화면이에요. autoplay를 넣으면 화면에 보일 때만 기본 장면을 반복해요. 원하는 대화를 직접 짤 수도 있어요.

<nw-phone style="width:330px">
  <nw-call autoplay></nw-call>
</nw-phone>

// 내가 짠 대화로 재생
call.run(async c => {
  c.goals(["weekend", "hiking"]);
  await c.say("So what did you end up doing this weekend?");
  await c.listen();
  await c.user("I go to hiking with my friends.");
  c.tick(1);
  c.fix({ text: "I went hiking with my friends.",
          note: "지난 일이라 과거형이에요" });
  await c.say("Nice! Where did you go?");
  c.done();
});

nw-home

Talk 탭이에요. 링을 누르고, 아래로 내려가 뉴스, 일상, 상황을 차례로 넘겨요.

<nw-home autoplay greeting="What's on your mind this evening?"></nw-home>

home.tapRing();  home.scrollTo(640);
home.tab(1);     home.tapRow(0);
home.lists = { news: [["chip", "Title", "Ai / Tech"]], everyday: [...], scenarios: [...] };

nw-speech

스피치 탭이에요. 챌린지를 열고, 녹음하면서 원고가 넘어가고, 점수와 순위 시트가 올라와요.

<nw-speech autoplay></nw-speech>

await speech.open();
await speech.record(4600, 21);   // ms, 타이머 초
await speech.result(81);
await speech.rankUp(14, 8);

모든 화면

폰 안에 넣는 화면 12개예요. 모두 autoplay로 화면에 보일 때만 돌고, beats="#섹션 .hows"를 주면 그 안의 [data-beat] 항목이 장면에 맞춰 강조돼요.

Three a day? No wonder you sound tired. It was busy week. I go to three meetings. It was a busy week. I went to three meetings.

nw-bubble · nw-fix

폰 없이 문장 하나만 크게 보여줄 때 써요. 호스트의 font-size로 전체 크기가 바뀌고, 17px이 앱과 같은 크기예요.

<nw-bubble who="self">Three a day? No wonder…</nw-bubble>
<nw-bubble who="me">It was busy week…</nw-bubble>
<nw-fix note="지난 일이라 과거형이에요">
  It was a busy week. I <b>went</b> to three meetings.
</nw-fix>

bubble.play();   // 단어가 하나씩 켜져요

잘라서 쓰기

폰을 다 보여줄 필요가 없으면 감싸는 상자에 높이와 overflow:hidden을 주면 돼요. 캐러셀이 이 방식이에요.

<div style="height:420px;overflow:hidden">
  <nw-phone style="width:300px"><nw-call autoplay></nw-call></nw-phone>
</div>
