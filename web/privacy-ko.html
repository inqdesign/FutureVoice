개인정보 처리방침

nawana · Dear RoRo, 뮌헨, 독일 · 시행일 2026년 7월 23일

nawana는 명시적인 동의 아래 딱 한 번 목소리를 클론해, 유창해진 나와 말하기를 연습하는 언어 학습 앱입니다. 목소리는 가장 개인적인 데이터입니다. 이 문서는 우리가 그것으로 무엇을 하고, 무엇을 하지 않는지를 정확히 설명합니다.

요약

  • 설정할 때 60초 녹음 한 번. 사용자가 직접 시작한 대화·연습 밖에서는 절대 녹음하지 않습니다.
  • 학습 데이터는 아이폰에 저장됩니다. 세션, 대화 기록, 드릴 카드, 단어장, 진행 상황은 기기에 저장되며 우리 서버에 올라가지 않습니다.
  • 광고 없음, 추적 없음, 분석 SDK 없음. 데이터를 광고 목적으로 판매하거나 공유하지 않으며, 앱에 제3자 추적 도구가 없습니다.
  • 언제든 삭제할 수 있습니다. 목소리를 다시 녹음하면 이전 클론은 영구 삭제됩니다. 계정을 삭제하면 음성 클론과 계정 데이터가 함께 삭제됩니다.

수집하는 것과 이유

데이터이유저장 위치
Apple 로그인 (사용자 식별자, 이메일)계정, 구독 권한, 초대 크레딧백엔드 (Supabase)
60초 음성 녹음개인 음성 클론 생성ElevenLabs에서 처리, 앱에는 클론 참조만 보관
대화·섀도잉 중 발화전사, 유창한 문장 제안, 발음 채점 — 핵심 기능가능한 경우 기기 내 전사, 대화 텍스트는 요청 시에만 처리되고 결과는 아이폰에 저장
구독·크레딧 잔액대화, 음성 생성, 섀도잉 이용Apple (구매) + 백엔드 (잔액)

소중히 다루는 목소리

  • 음성 클론은 사용자가 의도적으로 60초 설정 샘플을 녹음한 후에만 만들어집니다. 백그라운드 청취는 없습니다.
  • 클론은 오직 본인의 목소리만 재현합니다. nawana로 타인의 목소리를 클론할 수 없습니다.
  • 언제든 다시 녹음할 수 있습니다 — 새 클론이 만들어지면 이전 클론은 영구 삭제됩니다.
  • 목소리 또는 계정 전체를 앱 안에서 언제든 삭제할 수 있습니다 (Me → 계정).

데이터를 위탁 처리하는 곳

앱은 AI 제공사와 직접 통신하지 않습니다. 모든 요청은 자체 백엔드를 경유하므로, 제공사 API 키가 휴대폰에 존재하지 않습니다.

  • Supabase — 인증, 구독, AI 요청의 안전한 중계
  • ElevenLabs — 음성 클론 생성과 유창한 문장의 음성 합성
  • Google (Gemini) — 대화 응답, 유창한 문장 제안, 세션 분석. 텍스트만 전송되며 오디오는 Google에 전송되지 않습니다
  • Apple — Apple 로그인, 구독, 기기 내 음성 인식

위 수탁사는 계약에 따라 당사를 위해서만 데이터를 처리하며, 자체 목적으로 사용할 수 없습니다.

하지 않는 것

  • 광고 없음, 데이터 판매 없음, 앱 간 추적 없음
  • 앱 내 제3자 분석 SDK 없음
  • 사용자가 시작하지 않은 활동에서의 녹음 없음
  • 목소리·대화를 자사 또는 제3자 AI 모델 학습에 사용하지 않음

보관과 삭제

  • 학습 데이터(세션·드릴·진행 상황)는 기기에 저장되며 앱을 삭제하면 함께 사라집니다.
  • 음성 클론은 교체·삭제하거나 계정을 삭제할 때까지 유지됩니다.
  • 계정 삭제(앱 내 Me → 계정 → 계정 삭제)는 음성 클론, 계정 기록, 크레딧 잔액을 제거합니다. 구매 기록은 Apple의 정책에 따라 Apple이 보관합니다.

이용자의 권리

개인정보 처리 책임자는 Dear RoRo(독일 뮌헨)입니다. 이용자는 자신의 개인정보에 대한 열람·정정·이동·처리 제한·삭제를 요구할 권리와 감독 기관에 민원을 제기할 권리가 있습니다. 음성 데이터는 명시적 동의를 근거로 처리되며, 목소리 또는 계정 삭제로 언제든 동의를 철회할 수 있습니다.

아동

nawana는 만 13세 미만(또는 해당 국가의 최소 연령 미만) 아동을 대상으로 하지 않으며, 아동의 데이터를 고의로 수집하지 않습니다.
