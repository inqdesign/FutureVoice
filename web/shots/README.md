# web/shots — 앱 화면 에셋

**이 폴더에 아래 파일명 그대로 넣으면 페이지에 반영된다.**
영상은 iPhone 화면 녹화 원본(.mov)을 그대로 넣어도 됨 — 이름만 맞추면
변환(H.264 mp4, 무음, 웹 사이즈)은 Claude가 처리. 스틸은 .png.

캡처 공통: 세로 전체 화면(상태바 포함), 라이트 모드, 데이터가 차 있는 상태.
영상은 10–30초, 한 동작이 완결되게.
